# 魔數動物 & 魔數道具 完整參考手冊

---

## 一、魔數動物（Magic Animal）

玩家在個人資訊面板右側選擇一隻魔數動物夥伴。動物提供：
- **主動能力**：能量條充滿後可手動觸發一次
- **被動充能規則**：每次答對題目自動充能，部分動物在特殊事件下也會充能

能量條耗盡後使用主動能力，能量歸零。

### 魔數動物升級效果

魔數動物能力可升至 Lv3，費用結構同核心道具（300 → 500 → 1000 金幣）。

| 等級 | 效果 |
|------|------|
| **Lv1** | 基礎充能（無加成） |
| **Lv2** | **各動物獨特恢復能力 × 2** |
| **Lv3** | 獨特恢復能力 × 2（同 Lv2）＋ **答對題目基礎充能 × 2** |

充能公式：`gain = Clamp01( base × baseMult + unique × uniqueMult )`
- `baseMult`：Lv3 時 = 2，否則 = 1
- `uniqueMult`：Lv2+ 時 = 2，否則 = 1

> 各動物的 base / unique 定義見下方各動物說明。

### 🦁 獅王雷歐（Leo the Lion）

#### 主動能力：補一顆愛心

| | Game 1 / 2 / 4（子彈遊戲） | Game 3（外星人計數） |
|---|---|---|
| **效果** | 補一顆心 | 補一顆心 |
| **限制** | 只剩 1 顆心時才能觸發（miss == 2） | 只剩 1 顆心時才能觸發（lifeCount == 1） |
| **副作用** | 無 | 無 |
| **不符合時** | 顯示「你的生命很充足喔！」，不消耗能量 | 同左 |

#### 被動充能規則（答對題目）

| 組成 | Game 1 / 4 | Game 2 | Game 3 |
|------|-----------|--------|--------|
| **base**（受 Lv3 加成） | 0.020 | 0.020 | 0.020 + T×0.002 |
| **unique**（受 Lv2 加成）= 遊戲難度 Level 加成 | Level < 3：0 / Level 3~5：+0.010 / Level ≥ 6：+0.015 | Level < 10：0 / Level 10~19：+0.010 / Level ≥ 20：+0.015 | Level < 10：0 / Level 10~19：+T×0.002 / Level ≥ 20：+T×0.004 |

> T = 該題動畫時間（秒）。Game3 題目動畫越長（數量越多），充能越快。

### 🦉 魔法師歐洛（Olo the Owl）

#### 主動能力：顯示正確答案

| | Game 1（左右比大小） | Game 4（左右比大小） | Game 2（數字比大小） | Game 3（外星人計數） |
|---|---|---|---|---|
| **效果** | 顯示方向箭頭（→ 或 ←） | 顯示方向箭頭（→ 或 ←）＋**說出正確方向** | 直接說出正確數字 | 顯示左右外星人正確答案 |
| **限制** | 子彈須在畫面 50% 高度以上（viewport Y ≥ 0.5） | 同左 | 同左 | 無限制 |
| **副作用** | 當前題目標記 excluded（不計入研究數據、不充能） | 同左 | 同左 | 下一題差距限縮為 1（DifferenceModifier） |

#### 被動充能規則（答對題目）

| 組成 | Game 1 / 2 / 4 | Game 3 |
|------|---------------|--------|
| **base**（受 Lv3 加成） | 0.020 | 0.020 + T×0.002 |
| **unique**（受 Lv2 加成）= 分數表現加成 | bestScore < 10：+0.005 / 分數 ≥ 最高分 80%：**+0.015** / 老手爛局：**+0.005** | bestScore ≥ 10 且分數 ≥ 最高分 80%：+base×0.5 / 否則：0 |

> 鼓勵在「接近破個人紀錄」時充能加速，製造關鍵時刻感。Lv1 時 Game3 達標總和為 base×1.5，Lv2 達標為 base×2.0，Lv3 達標為 base×3.0。

### 🐱 喵星人蜜亞（Mira the Cat）

#### 主動能力：下一題最簡單

| | Game 1 / 2 / 4 | Game 3 |
|---|---|---|
| **效果** | 下一題強制 Level 1（LevelModifier） | 下一題強制最簡單配置（2v1 或 1v2 隨機） |
| **限制** | 無 | 無 |
| **副作用** | 無（設計原則：延遲滿足，不影響當前題目） | 無 |

#### 被動充能規則

| 觸發時機 | 組成 | Game 1 / 2 / 4 | Game 3 |
|---------|------|---------------|--------|
| **答對題目** | **base**（受 Lv3 加成） | 0.020 | 0.020 + T×**0.0035** |
| **答對題目** | unique | 無（Cat 的 unique 全在失命） | 無 |
| **失命 Lv1** | 失命充能 | +0.150 | +0.300 |
| **失命 Lv2+** | 失命充能（Cat 特例：固定 +0.15，非 ×2） | +0.150 **+0.150 = 0.300** | +0.300 **+0.150 = 0.450** |
| **每日結算（Game3）** | 溢出充能（`OnDailyTimeExhausted`） | — | 每剩餘命 **+0.150**，可超過 1.0 |

> **Cat 特例說明**：其他動物的 Lv2 unique 為 ×2 倍率，但貓咪失命充能若用 ×2 在 Game3 會達到 +0.60（過強），故改為固定 +0.15 的平坦加成。最終：Game1/2/4 失命 Lv2 = 0.30；Game3 失命 Lv2 = 0.45。

### 魔數動物充能速覽表

| 動物 | 充能機制關鍵因子 | 失命充能 | 使用後 |
|------|---------------|---------|--------|
| 🦁 獅王雷歐 | 題目 Level 高低 | 無 | **溢出保留**（remainder = charge - 1.0） |
| 🦉 魔法師歐洛 | 當前分數是否接近個人最高分 | 無 | 溢出保留 |
| 🐱 喵星人蜜亞 | 穩定小量 + **失命時大量** + **每日結算溢出** | ✅ Game1/2/4: +0.15；Game3: +0.30 | 溢出保留 |
| 🐶 好朋友迪米 | Combo 連答數 | 無 | 溢出保留 |
| 🐢 小管家圖圖 | Game3 依題目動畫時長；Game1/2/4 固定 | 無 | 溢出保留 |

> **溢出保留**：能力觸發後，charge 超過 1.0 的部分（`charge - 1.0`）會保留作為下次的起始充能，而非歸零。僅 Cat 的每日結算 (`OnDailyTimeExhausted`) 能夠產生真正的 charge > 1.0。
>
> 詳細充能公式與平衡評估請參閱 [`magic-animal-charge-formulas.md`](magic-animal-charge-formulas.md)。

## 二、魔數道具（Magic Item / Ability）

道具分為**主動能力**（遊戲中手動觸發）和**被動能力**（自動生效），各占一個裝備槽。

### 裝備槽系統

| 槽位 | 數量 | 說明 |
|------|------|------|
| 主動能力槽 | 1 格 | 遊戲中 HUD 右側顯示按鈕，手動點擊觸發 |
| 被動能力槽 | 1 格 | 自動生效，無需操作 |

- 每題最多使用 **1 次**主動能力（`_abilityUsedThisQuestion` 標記）
- 每日使用次數上限由 Server 控制，UTC 00:00 重置
- 消耗次數時呼叫 `consume_ability_use.php`，以 HMAC-SHA256 簽章防重放攻擊
