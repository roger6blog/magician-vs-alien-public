# 星星與結晶獲得條件比較

分析來源：Unity 客戶端（C#）、PHP 後端，排除 .md 檔案。

---

## 一、星星獲得條件

**核心決定因素：你答得多好**

```
當日加權分數 = Σ（每局答對題數 × 難度乘數）
```

- 每局結束（死亡或時間到）就累加一次
- 同一天可多局累積，分數只增不減
- 三款遊戲各自獨立計算

### 決定分數高低的兩個變數

| 變數 | 你能控制的行為 |
|------|-------------|
| 答對題數 | 專注答題、減少錯誤 |
| 難度等級 | 撐到越高難度，每題乘數越大 |

### 難度乘數對照

**Game 1（數字比大小 / 子彈遊戲）**

| 難度等級 | 乘數 |
|---------|------|
| Lv 5 以上 | 3.0× |
| Lv 4 | 2.5× |
| Lv 3 | 2.0× |
| Lv 2 | 1.5× |
| Lv 1 | 1.0× |

**Game 2（怪物排序）**

| 速度等級（mylevel / 10） | 乘數 |
|------------------------|------|
| 3 以上 | 2.5× |
| 2 | 2.0× |
| 1 | 1.5× |
| 0 | 1.0× |

**Game 3（外星人計數）**

| 當局答對題數 | 乘數 |
|------------|------|
| > 15 題 | 3.0× |
| > 10 題 | 2.5× |
| > 6 題 | 2.0× |
| > 2 題 | 1.5× |
| ≤ 2 題 | 1.0× |

### 星數門檻（當日加權分數）

| 加權分數 | 星數 |
|---------|------|
| ≥ 120 | ★★★★★ |
| ≥ 80 | ★★★★ |
| ≥ 45 | ★★★ |
| ≥ 20 | ★★ |
| ≥ 1 | ★ |
| 0 | 無星 |

### 特殊影響

裝備 **LuckyStar** 被動能力 → 結算星數 × 2（上限 5 星）

## 二、結晶獲得條件

**核心決定因素：你死多少次 × 你玩多久**

```
結晶數 = floor( baseCrystal(死亡次數) × timeCoefficient(有效遊玩秒數) )
保底：timeCoefficient > 0 且計算結果 = 0 時，給 1 顆
```

- 遊戲時間歸零 或 玩家主動結算時才計算
- 同一天內只補差額，不重複給

### 決定結晶多少的兩個變數

| 變數 | 你能控制的行為 |
|------|-------------|
| 死亡次數（越少越好） | 避免失誤、保存生命值 |
| 有效遊玩時間（越長越好） | 持續遊玩，至少撐過 4 分鐘門檻 |

### baseCrystal（依當日死亡次數）

| 當日死亡次數 | 基礎結晶 |
|------------|---------|
| 0 ~ 1 次 | 5 顆 |
| 2 ~ 4 次 | 4 顆 |
| 5 ~ 8 次 | 3 顆 |
| 9 ~ 12 次 | 2 顆 |
| 13 次以上 | 1 顆 |

### timeCoefficient（依有效遊玩時間）

| 有效遊玩時間 | 係數 |
|------------|------|
| ≥ 8 分鐘（480 秒） | 1.0（100%） |
| 6 ~ 8 分鐘（360 秒） | 0.7（70%） |
| 4 ~ 6 分鐘（240 秒） | 0.4（40%） |
| < 4 分鐘 | 0（不發放） |

### 額外來源

連續登入獎勵可直接獲得結晶（非遊玩計算所得）：

| 天數 | 結晶 |
|------|------|
| Day 5 | 1 顆 |
| Day 10 | 2 顆 |
| Day 13 | 2 顆 |

## 三、差異比較

| 比較維度 | 星星 | 結晶 |
|---------|------|------|
| **衡量的本質** | 表現品質（答得好不好） | 遊玩投入（活多久、玩多久） |
| **核心輸入** | 答對題數 + 難度等級 | 死亡次數 + 有效遊玩時間 |
| **計算時機** | 每局結束立即累加 | 時間歸零 / 主動結算才結算 |
| **當日累積方式** | 累加（多局分數疊加） | 差額補給（只補不重複） |
| **每日上限** | 5 星（硬上限） | 無明確上限，理論最高 5 顆（死亡 0~1 次 + 遊玩 ≥ 8 分鐘） |
| **遊戲間關係** | Game1 / 2 / 3 各自獨立統計 | 每次結算以單一遊戲為單位 |
| **能力影響** | LuckyStar 可 × 2 | 無任何能力可加成 |
| **額外來源** | 無（只靠遊玩） | 連續登入獎勵可直接獲得 |
| **歷史追蹤** | total_star 累計、best_star 最高紀錄（伺服器） | 無歷史累計，只看餘額 |
| **設計意圖** | 鼓勵**答得準、挑戰高難度** | 鼓勵**不死、持續遊玩** |

## 四、關鍵衝突點

兩套系統在某些情境下會產生**矛盾誘因**：

### 高難度 vs 低死亡
難度越高 → 答錯或被打死的機率越高 → 星星加快但結晶減少。玩家必須在「衝高星星」和「保命拿結晶」之間取捨。

### 多局 vs 早結算
死了立刻重玩可以繼續累積加權分數（星星），但死亡計數同時在增加（結晶的 baseCrystal 下降）。磨到 5 星的代價可能是結晶只剩 1~2 顆。

### 時間門檻的斷崖
結晶的 timeCoefficient 是階梯式（4 分鐘以下直接歸零），短暫遊玩完全沒有結晶；而星星只要答對就有分，沒有時間門檻。
